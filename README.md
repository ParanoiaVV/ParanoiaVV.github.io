# Тест по C#

Адаптивное статическое веб-приложение с тестом по C#. Вопросы можно загружать из публичной Google Sheets таблицы.

## Подключение Google Sheets

В `app.js` укажите CSV-ссылку в `GOOGLE_SHEET_CSV_URL`. Таблица должна быть опубликована в интернете и содержать заголовки:

`question, option1, option2, option3, option4, answer, category`

В колонке `answer` хранится номер правильного варианта от 1 до 4. Если ссылка не указана или таблица недоступна, приложение работает на встроенном демо-наборе.

## Запуск и публикация

Проект не требует сборки: откройте `index.html` или разместите папку на любом статическом хостинге (GitHub Pages, Netlify, Vercel или Cloudflare Pages).
